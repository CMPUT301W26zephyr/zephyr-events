# Generating Javadoc

Make the script executable (only needed once):

``` bash
chmod +x ./scripts/gen-javadoc.sh
```

## Generate and open docs

``` bash
./scripts/gen-javadoc.sh
```

## Open docs without regenerating

``` bash
./scripts/gen-javadoc.sh -o
```

## Output location

Docs are generated at:

    javadoc/index.html
