# Lottofy

## Event Lottery System Application
This is a lottery-based event registration Android app where you can create your own events and join waitlists for other events. Sign up to become a user or admin, upload event posters and avatar images, enable geolocation radius, add co-organizers, generate QR codes, post comments, and so much more with Lottofy!

### Code
Uses a modified MVC architecture. Written mainly in Java and XML, with backend Firebase Cloud Functions written in JavaScript.
